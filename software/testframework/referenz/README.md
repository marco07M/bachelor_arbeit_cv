Hier genau eine `.csv` oder `.xlsx` mit den Referenzteilnehmern ablegen.
Standardspalten: Class ID, User ID, First Name, Last Name, Organization.
Die User-ID-Spalte darf fehlen. Organization enthält das Kurzzeichen.
Eine Datei darf mehrere Schulungen enthalten. IDs als Text mit führenden Nullen speichern.
Die synthetische CSV-Vorlage liegt unter `../beispiele/referenz.csv`.
Die Referenzdatei wird ausschließlich nach der Extraktion zur Bewertung verwendet.
