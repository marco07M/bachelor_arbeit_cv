\chapter{Abstract}

Within the training administration process investigated at the BMW Group, attendance at internal and external training sessions is documented on physical participant lists that are subsequently scanned or photographed as Portable Document Format (\acs{pdf}) files and manually transcribed into the internal training management system. Over recent years, approximately 6,000 such \acs{pdf} documents have accumulated that had to be entered manually, illustrating the substantial recurring effort and error potential of manual transcription. To automate this process for future incoming participant lists, heterogeneous table layouts, rotated scan pages, multi-page tables lacking repeated column headers, mixed printed and handwritten entries, strict BMW data privacy regulations, and limited local Graphics Processing Unit (\acs{gpu}) memory (\mbox{16\,GiB} Video Random-Access Memory, \acs{vram}) must be addressed.

This bachelor's thesis systematically designs, implements, and empirically evaluates Artificial Intelligence (\acs{ki})-based information extraction architectures to support the automated transfer of future incoming participant lists at BMW (while leveraging the already recorded historical document archive and its corresponding system exports as a real-world reference and evaluation corpus), capturing five target fields per attendee: \emph{first name}, \emph{last name}, \emph{personnel number} (\emph{Benutzer} / \emph{User~\acs{id}}), \emph{department} (\emph{organization/short code}), and the visual \emph{presence of a signature} (strictly limited to visual presence detection without biometric verification). To this end, a modular, purely local Python evaluation framework was developed to benchmark five selected extraction approaches (\texttt{start\_testframework\_5.cmd} / \texttt{configs/benchmark-five.yaml}) under controlled conditions: (1)~a classical rule- and template-based Optical Character Recognition (\acs{ocr}) baseline using Tesseract without a language model (\texttt{ocr\_rules}), (2)~Tesseract \acs{ocr} and (3)~PaddleOCR/PP-StructureV3 each paired with the local text-only Large Language Model (\acs{llm}) \texttt{Qwen3-4B-Instruct-2507} (\texttt{ocr\_llm} and \texttt{paddle\_llm}), (4)~an \acs{ocr}-free Vision-Language Model (\acs{vlm}) operating directly on the page image via \texttt{Qwen3-VL-4B-Instruct} (\texttt{vlm}), and (5)~a controlled hybrid architecture (\texttt{ocr\_vlm}) that combines an independently executed upstream PaddleOCR pass with the identical \acs{vlm}, enabling the model to jointly evaluate the page image and structured \acs{ocr} cell evidence. In addition, a strictly isolated Application Programming Interface (\acs{api}) evaluation package was designed for BMW corporate workstations.

To ensure extraction reliability and methodological rigor, the framework incorporates two-stage automatic page orientation (Orientation and Script Detection, \acs{osd}, with a four-orientation \acs{ocr} fallback), non-destructive background normalization, a lossless observation ledger, geometry-verified column inheritance for headerless continuation pages, row-individual given/family name splitting, strict literal and spatial evidence validation, and a multi-dimensional metric and causal error analysis pipeline. Across the evaluated real development samples (a two-page mixed document with 72 reference fields, a three-document benchmark with 184 reference fields, and a ten-document audit with 620 reference fields), \texttt{paddle\_llm} (51.09\,\% exact field recall, 60.65\,\% exact field $F_1$ on the three-document benchmark) and \texttt{ocr\_vlm} (47.83\,\% exact field recall, increasing to 52.17\,\% after verified continuation-page repair) achieve the highest extraction quality. Causal error analysis reveals that a substantial share of apparent field losses stems not from recognition blindness alone, but from rotated scans, headerless continuation pages, token-budget truncations, and discrepancies between external course completion spreadsheets and visibly present document fields. A final confirmatory evaluation on an independently annotated pilot and test sample is fully prepared within the framework as the immediate next step.

\textbf{Keywords:} Information Extraction, Participant Lists, Optical Character Recognition (\acs{ocr}), Large Language Models (\acs{llm}), Vision-Language Models (\acs{vlm}), Document AI, Local AI Benchmarking
